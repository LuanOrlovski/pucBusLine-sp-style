# Projeto WEB RotaFácil
projeto acâdemico voltado para ajudar calouros da PUCPR a utilizarem rotas de transporte publico proximos a universidade.

# Sobre

O RotaFácil facilita o acesso às informações das linhas-tubo de Curitiba, especialmente para quem depende do transporte público diariamente. Ajudando moradores e estudantes a consultar horários e trajetos com rapidez.

# Funcionalidades
- Consulta de linhas de ônibus por estação (Paiol e PUC), com sentido, dias de operação e horários
- Visualização da rota como linha de trajeto, destacando o ponto atual e as estações-tubo
- Navegação por seções (Início, Sobre, Rotas Paiol, Rotas PUC) 

# Tecnologias web utilizados
HTML, JS e CSS
